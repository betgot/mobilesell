# 📱 MobileSell

Браузерный симулятор перепродажи телефонов. Покупайте б/у смартфоны, чините их и перепродавайте дороже.

## 🚀 Запуск
Весь проект находится в одном HTML-файле и не требует установки:

1. Скачайте репозиторий или сам `.html` файл.
2. Откройте `index.html` в любом браузере.

## 🛠️ Стек
* HTML5 / CSS3 / Vanilla JS
